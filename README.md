# 🏠 居委会排班表 · 纯净开源版

> 一个适合 **居委会、社区、办公室、物业值班、节假日值守、活动排班** 等场景使用的单文件 HTML 排班工具。  
> 支持 **人员管理、WPS / Office / Excel 导入、自动排班、排班顺序学习、请假冲突检测、节假日 API 导入、打印、备份、飞书 / 钉钉推送**。

---

## 📌 项目简介

**居委会排班表 · 纯净开源版** 是一个基于 **HTML + CSS + JavaScript** 制作的轻量级排班工具。

它的目标是：让不懂代码、不熟悉复杂办公系统的人，也能快速完成日常值班排班。

本工具无需安装软件、无需数据库、无需后端服务。  
下载后直接使用浏览器打开 `index.html` 即可运行。

适合以下场景：

- 居委会值班排班
- 社区工作者排班
- 办公室晚班排班
- 周末值班排班
- 节假日值守排班
- 物业值班排班
- 活动现场值守安排
- 小团队轮班表制作

---

## 🧼 纯净开源版说明

本仓库为 **纯净开源版**，适合公开发布到 GitHub。

本版本不内置任何真实隐私数据：

- 不内置真实工作人员姓名
- 不内置真实联系电话
- 不内置真实居委会地址
- 不内置真实书记 / 民警 / 社工信息
- 不内置真实值班安排
- 不内置真实请假记录
- 不内置飞书 Webhook
- 不内置钉钉 Webhook
- 不内置 Cloudflare Worker 推送口令
- 不自动创建默认示例人员

首次使用时，需要自行添加人员，或通过 WPS / Office / Excel / CSV 导入。

> ⚠️ 如果你要公开发布本项目，请不要把真实 JSON 备份、真实排班表、Webhook、PUSH_TOKEN、单位内部截图等内容上传到 GitHub。

## ✨ 功能特点

### 👥 人员管理

支持对值班人员进行管理：

- 添加人员
- 编辑人员
- 启用人员
- 停用人员
- 删除人员
- 批量添加人员
- 从导入表格中自动创建人员

人员字段包括：

| 字段 | 说明 |
|---|---|
| 姓名 | 值班人员姓名 |
| 职务 | 例如书记、干部、社工、工作人员 |
| 负责小区 | 可选，用于内部查看 |
| 联系电话 | 可选，不建议公开发布 |

人员状态说明：

| 状态 | 说明 |
|---|---|
| 在岗 | 参与自动排班 |
| 停用 | 不参与自动排班，但历史记录保留 |

---

### 🧠 排班顺序学习

支持从旧 WPS / Office / Excel / CSV 排班表中学习原有轮转顺序。

例如旧表是：

```text
日期        星期    班次        值班人员
2026-05-01  周五    节假日值班  张三
2026-05-02  周六    周末白班    李四
2026-05-03  周日    周末白班    王五
2026-05-04  周一    工作日晚班  赵六
```

系统可以学习出：

```text
张三 → 李四 → 王五 → 赵六
```

支持学习：

- 通用人员轮转顺序
- 工作日晚班顺序
- 周末白班顺序
- 节假日值班顺序
- 调休补班晚班顺序

---

### 📥 导入排班时自动学习顺序

新版支持在导入排班时，自动学习排班顺序。

导入排班时可以选择：

- 导入排班后自动学习通用顺序和班次顺序
- 只学习按班次分别轮转的顺序
- 只学习通用人员顺序
- 不自动学习，只导入排班

推荐选择：

```text
导入排班后自动学习通用顺序和班次顺序
```

这样导入旧排班表后，以后自动排班就可以直接使用学习到的顺序。

---

### ✨ 自动排班

支持一键生成当前月份排班。

自动排班支持：

- 按人员列表顺序排班
- 按学习顺序排班
- 按不同班次分别轮转
- 自动避开请假人员
- 自动避开停用人员
- 生成前预览
- 确认后应用

自动排班不会直接强制覆盖当前日历，而是先生成预览，避免误操作。

---

### 📅 节假日 / 调休 API 导入

支持通过 API 导入节假日、休息日和调休补班日。

默认 API 示例：

```text
https://timor.tech/api/holiday/year/{year}
```

其中 `{year}` 会自动替换为填写的年份。

例如填写：

```text
2026
```

系统会请求：

```text
https://timor.tech/api/holiday/year/2026
```

导入后，系统会识别：

- 法定假日
- 休息日
- 调休补班

排班逻辑参考：

| 日期类型 | 排班方式 |
|---|---|
| 普通工作日 | 工作日晚班 |
| 周末 | 周末白班 |
| 法定节假日 / 休息日 | 节假日值班 |
| 调休补班日 | 调休补班晚班 |

---

### 🩺 请假记录

支持添加请假记录：

- 请假人员
- 开始日期
- 结束日期
- 请假原因

如果请假人员仍被安排值班，日历会显示冲突提示。

---

### ⚠️ 冲突检测与一键修复

支持检查：

- 请假人员仍被排班
- 停用人员仍被排班
- 导入旧表后产生冲突
- 自动排班后产生冲突

点击：

```text
⚠️ 修复冲突
```

系统会尝试自动替换为其他可排班人员。

如果没有合适人员，会清空该日排班，等待人工处理。

---

### 🔁 手动换班

支持点击日期后进行手动修改或换班。

换班成功后，如开启推送提醒，可以自动推送换班信息到飞书 / 钉钉。

---

### 📥 多格式导入

支持导入：

- JSON 备份
- CSV 文件
- TXT 文件
- WPS / Excel / Office 复制内容
- 旧排班表内容

推荐 CSV 格式：

```text
日期,星期,日期类型,班次,值班人员,时间,备注
```

示例：

```text
2026/5/6,星期二,工作日,工作日晚班,郑楠,18:00-21:00,
2026/5/7,星期三,工作日,工作日晚班,林峰,18:00-21:00,
2026/5/8,星期四,工作日,工作日晚班,赵磊,18:00-21:00,
2026/5/9,星期六,调休上班日,调休上班晚班,孙丽,18:00-21:00,5月9日周六调休上班
```

支持自动识别：

- UTF-8
- GBK
- GB18030

> 如果 WPS 普通 CSV 中文乱码，建议另存为 `CSV UTF-8` 后再导入。

## 🔔 飞书 / 钉钉推送配置

### 为什么需要 Cloudflare Worker？

不建议前端 HTML 直接请求飞书 / 钉钉 Webhook。

原因：

1. 浏览器可能有跨域限制
2. Webhook 写在前端不安全
3. 不适合公开发布到 GitHub
4. Worker 方便统一转换消息格式

---

### Worker 需要配置的 Secret

在 Cloudflare Worker 中配置：

```text
PUSH_TOKEN
FEISHU_WEBHOOK
DINGTALK_WEBHOOK
```

只用飞书：

```text
PUSH_TOKEN
FEISHU_WEBHOOK
```

只用钉钉：

```text
PUSH_TOKEN
DINGTALK_WEBHOOK
```

---

### 排班表中填写

点击顶部：

```text
🔔 推送
```

填写：

| 配置项 | 说明 |
|---|---|
| 推送中转接口地址 | Cloudflare Worker 地址 |
| 推送平台 | 飞书 / 钉钉 |
| 推送口令 | Worker 中设置的 PUSH_TOKEN |
| 推送格式 | 普通文本 / 表格文本 / Markdown 表格 / 飞书卡片表格 |
| 人员变动自动提醒 | 人员修改后是否自动推送 |
| 请假变动自动提醒 | 请假新增、编辑、删除后是否自动推送 |
| 换班自动提醒 | 换班成功后是否自动推送 |

## 🔐 数据安全说明

本工具默认使用浏览器本地存储，即 `localStorage`。

这意味着：

```text
数据保存在当前浏览器
不是云端数据库
不会自动同步到其他电脑
```

可能导致数据丢失的情况：

- 清理浏览器缓存
- 更换浏览器
- 更换电脑
- 使用无痕模式
- 系统重装
- 手动重置数据

建议：

```text
正式排班前导出 JSON 备份
正式排班后导出 JSON 备份
重要修改前先备份
```

## ❓ 常见问题

### 1. 打开后为什么没有人员？

纯净开源版默认不创建示例人员，需要自行添加或导入。

---

### 2. 数据保存在哪里？

保存在当前浏览器本地，不是云端数据库。

---

### 3. 换电脑后数据还在吗？

不在。需要导出 JSON 备份，再在新电脑导入恢复。

---

### 4. WPS / Excel 导入失败怎么办？

建议整理成：

```text
日期,星期,班次,值班人员,备注
```

再导入。

---

### 5. CSV 中文乱码怎么办？

建议另存为：

```text
CSV UTF-8
```

新版会尽量自动识别 GBK / GB18030。

---

### 6. 为什么不支持直接上传 xlsx？

`.xlsx`、`.xls`、`.et` 不是普通文本文件。  
建议先在 WPS / Excel 中另存为 CSV。

---

### 7. 自动排班不符合预期怎么办？

请检查：

- 是否已添加人员
- 人员是否在岗
- 是否导入节假日
- 是否添加请假
- 是否学习旧排班顺序
- 自动排班方式是否选择正确

---

### 8. 推送失败怎么办？

检查：

- Worker 地址是否正确
- PUSH_TOKEN 是否正确
- Worker 是否部署成功
- 飞书 / 钉钉 Webhook 是否配置到 Worker Secret
- 机器人安全设置是否限制关键词

---

### 9. 可以多人协同吗？

当前版本不是多人协同系统。

它更像：

```text
可以在线打开的本地排班工具
```

每个人浏览器中的数据可能不同。

如需多人协同，需要后续接入云数据库、登录系统和权限管理。

---

### 10. 可以在国产系统使用吗？

可以。银河麒麟、统信 UOS 等系统，只要有现代浏览器，一般都可以使用。
