# 居委会排班表

一个面向居委会、社区办公室和值班排班场景的单文件 HTML 排班工具。

- 适用场景：居委会值班、社区办公室排班、物业值班、小型单位轮班、节假日值守
- 当前版本：V2.7.0 稳定版
- 功能标签：`单文件 HTML` `本地存储` `自动排班` `导入导出` `打印` `飞书推送` `隐私张贴版`

## 项目简介

居委会排班表是一款面向居委会、社区、物业、办公室值班排班场景的本地化工具。它主要用于人员管理、请假记录、节假日/调休管理、自动排班、值班统计、数据健康检查、排班表打印和飞书推送提醒。

本工具不需要服务器，也不需要数据库。下载或复制 `index.html` 后，直接用浏览器打开即可使用。数据默认保存在当前浏览器本地，适合办公室工作人员、小白用户和需要快速生成排班表的使用场景。

它不是复杂考勤系统，而是一个轻量、直观、可离线使用的排班辅助工具。

## 功能亮点

- 人员管理：支持添加、批量添加、编辑、停用/启用和删除人员。
- 自动排班：支持按规则生成排班，并先预览、后确认应用。
- 请假记录：记录人员请假时间，并在排班中提示冲突。
- 节假日/调休管理：支持法定假日、休息日、调休补班等日期类型。
- 导入前预检：导入排班前先展示识别结果，不会直接覆盖数据。
- JSON 备份与恢复：适合完整迁移和长期备份。
- CSV/TXT/表格文本导入：支持从 WPS、Excel、Office 复制表格文本。
- 数据健康检查：检查未排班、人员不存在、停用人员排班、请假冲突、连续值班等问题。
- 值班次数统计：统计各类班次次数、总次数和加权分。
- 单日调整原因与操作日志：手动调整值班人时记录原因，便于追溯。
- 隐私张贴版打印：适合公告栏张贴，隐藏手机号、负责小区、备注和冲突提示。
- 飞书推送：支持通过中转服务推送飞书卡片提醒。
- 深色模式：支持浅色/深色切换。
- 移动端适配：可在手机或窄屏设备上查看和操作。

## 使用教程

### 1. 填写居委会信息

点击左侧居委会信息区域的“编辑信息”，可以填写或修改：

- 社区名称
- 联系电话
- 地址
- 书记
- 社区民警
- 民警电话
- 负责小区

这些信息会用于页面展示、打印标题和推送内容。公开演示时请使用测试信息，不要填写真实单位信息。

📸 截图建议：这里放【编辑居委会信息】截图

### 2. 添加值班人员

在左侧“人员管理”区域，可以单个添加人员，也可以点击“批量添加”一次性导入多名人员。

单个添加时可填写：

- 姓名
- 职务
- 负责小区
- 联系电话

批量添加时可以从 WPS、Excel、Office 或文本文件中复制人员名单。建议公开演示时使用“测试人员A、测试人员B、测试人员C”等虚拟姓名。

📸 截图建议：这里放【人员管理】截图

### 3. 添加请假记录

在左侧“请假记录”中点击“添加”，选择人员、开始日期、结束日期和请假原因。

请假记录会影响冲突检测。如果某人请假期间仍被安排值班，日历和数据健康检查会提示冲突，方便及时调整。

📸 截图建议：这里放【请假记录】截图

### 4. 添加节假日 / 调休

在左侧“节假日 / 调休”中可以添加：

- 法定假日
- 休息日
- 调休补班

日期类型会影响班次判断：

- 普通工作日：工作日晚班
- 周末：周末白班
- 节假日 / 休息日：节假日值班
- 调休补班：调休补班晚班

📸 截图建议：这里放【节假日调休管理】截图

### 5. 自动排班

点击顶部“自动排班”，可以根据当前人员、请假记录、节假日和调休信息生成排班。

自动排班前建议先检查：

- 是否已经添加所有值班人员
- 是否已经录入请假记录
- 是否已经设置节假日和调休补班
- 是否有停用人员仍在旧排班中

自动排班会先生成预览，不会立即写入。确认预览无误后，再点击“确认应用”。如果应用后发现问题，可以点击顶部“撤销”。

📸 截图建议：这里放【自动排班预览】截图

### 6. 导入排班表

点击顶部“导入”，可以导入 CSV、TXT 或从 WPS/Excel/Office 复制出来的表格文本。

推荐表头示例：

```text
日期,星期,班次,值班人员,备注
2026-05-01,星期五,工作日晚班,测试人员A,
2026-05-02,星期六,周末白班,测试人员B,
```

导入前系统会先进行预检，展示：

- 总行数
- 有效排班行数
- 涉及月份
- 识别到的人员
- 未识别或跳过的行

只有点击“确认导入”后，数据才会写入。

📸 截图建议：这里放【导入前预检】截图

### 7. 数据健康检查

在“更多功能”中点击“数据健康检查”，可以检查当前月份是否存在明显问题。

可检查内容包括：

- 未排班日期
- 值班人员不存在
- 停用人员仍然被排班
- 请假人员仍然被排班
- 同一人连续两天值班
- 单人排班次数明显高于平均值

数据健康检查只展示问题，不会自动修改排班。

📸 截图建议：这里放【数据健康检查结果】截图

### 8. 值班统计

在“更多功能”中点击“值班统计”，可以查看当前月份每个人的值班情况。

统计内容包括：

- 工作日晚班次数
- 周末白班次数
- 节假日值班次数
- 调休补班晚班次数
- 总次数
- 加权分

加权分用于辅助判断排班是否明显偏多或偏少。自动统计只能辅助判断，最终仍建议人工复核。

📸 截图建议：这里放【值班统计表】截图

### 9. 打印排班表

点击顶部“打印”，可以选择不同打印模板。

支持模板：

- 简洁版
- 标准版
- 归档版
- 隐私张贴版

隐私张贴版适合公开张贴，例如公告栏、门卫室、值班室外墙等场景。该模板只显示日期、班次和值班人姓名，会隐藏手机号、负责小区、备注、调整原因、冲突提示和操作按钮。

## 数据保存说明

本工具默认使用浏览器本地存储，数据主要保存在当前浏览器中。

请注意：

- 换电脑后，原电脑浏览器中的数据不会自动同步。
- 换浏览器后，数据也不一定存在。
- 清理浏览器缓存或网站数据后，排班数据可能丢失。
- 正式使用前后都建议导出 JSON 备份。
- 不建议在公共电脑长期保存真实人员信息。

如果需要迁移到另一台电脑，请先导出 JSON 文件，再在新电脑中导入。

## 备份与恢复

点击“导出/备份”，再点击“导出完整 JSON”，即可保存完整数据备份。

JSON 备份通常包含：

- 人员名单
- 排班数据

建议每次正式排班后保存一份备份，例如：


## 常见问题

### Q1：为什么刷新页面后数据还在？

因为本工具使用了浏览器本地存储。只要没有清理浏览器数据，刷新页面后通常还能看到之前保存的排班。

### Q2：换电脑后数据还在吗？

不一定。数据保存在当前电脑的当前浏览器中。换电脑前请先导出 JSON 备份，再到新电脑导入。

### Q3：能不能多人同时在线使用？

当前版本是单文件本地工具，不是多人在线协同系统。如果多人同时编辑同一份排班，需要人工约定谁负责最终版本。

### Q4：自动排班一定公平吗？

不一定。自动排班只能辅助生成结果，建议结合“值班统计”和人工复核，特别是节假日、调休补班和特殊人员安排。

### Q5：飞书推送失败怎么办？

请检查 Worker 地址、飞书 Webhook、网络状态、推送口令和推送格式。建议先用测试环境验证，不要直接使用正式机器人地址公开测试。

### Q6：打印时为什么样式和页面不一样？

打印模式会自动隐藏按钮、侧栏、弹窗等操作区域，并根据模板优化纸张输出，所以打印样式会和页面查看样式不同。

### Q7：隐私张贴版适合什么场景？

适合公告栏、值班室、门口张贴等公开场景。它只显示必要排班信息，避免暴露手机号、负责小区、备注和冲突提示。
